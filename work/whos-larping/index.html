Who's Larping?

Roblox social deduction experience. Someone at the table is faking it.

Oct 2026Building

whos-larping.txtNovember 2026page 001

What it is

Who’s Larping? is a Roblox social deduction experience. Everyone at the table is dressed as the same internet character, a “brainrot” like Tralalero Tralala or Shrek, except the larper. The larper sees grey dummies and has to fake it. The look borrows from Buckshot Roulette: a sepia, hatched room under heavy dither, grain and a vignette.

How it works

Players meet in a lobby called The Back of the Club, which has three doors. Once four people stand on a door’s mat, it counts down and sends up to ten of them to a fresh server with the table. The house then picks a show. In Shootout (five or more players), the larper stays hidden all match and the table votes on who to shoot. The head only fires with a majority, and a caught larper gets one last guess at the character. Faking It works at any size: a points mode with a new character and a new larper every round.

The rounds, Hands Up, Doodle and Caption This, only give raw evidence. The table has to talk it out before every vote. I mock up the UI in Python first, drawn at half resolution with Bayer dither, and the same code exports the textures the game uses.

Where it stands

I build it live in Roblox Studio. The core match, both shows, the lobby, a cosmetics shop and saved profiles are scripted. It’s still a work in progress.
