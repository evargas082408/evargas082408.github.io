Crow

An alarm clock you can't snooze, unplug or uninstall.

Oct 2026Designed, not built

crow.txtNovember 2026page 001

What it is

Crow is an alarm clock you can’t snooze, unplug or uninstall your way out of. It is a battery-backed ESP32 clock with a crow’s face on a small OLED, plus a phone app that holds the only key to it. Delete the app and the key goes with it, but the alarms live on the clock, so it keeps ringing.

How it works

When the alarm goes off, the clock makes up a fresh random challenge. The app answers it with an HMAC proof over Web Bluetooth, but only after you solve a couple of quick puzzles. Each wrong answer makes the clock louder, and unplugging it mid-ring jumps straight to the loudest level. Without the key, it rings until you re-pair, pass a count-off on a hidden SOS pin, or reach the mercy limit, 45 minutes by default.

A web simulator puts a virtual clock, running a port of the firmware, next to a virtual phone running the real app. The enclosure is a FreeCAD model built by a Python script, and the build fails if any two parts overlap.

Where it stands

The firmware compiles for a LOLIN D32 but has not been flashed to a board. The enclosure is fit-checked against datasheet sizes and has not been printed. The Bluetooth link follows the protocol spec but has not met a physical clock. The simulator and app logic work, and 208 checks run on every push. The FreeCAD rebuild is still an open pull request.
