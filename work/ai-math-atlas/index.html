AI Math Atlas

Notes on the math behind neural networks, linked into a graph.

Oct 2026Building

What it is

AI Math Atlas is a learning project I started to understand neural networks and generative AI through the math underneath them. The first section is a map you can navigate: 63 short notes, one per concept, linked into a knowledge graph.

How it works

Each note is a markdown file with LaTeX math and a small header: title, section, the core formula, what it builds on and what uses it. The notes cover six areas: foundations (linear algebra, calculus, probability, information theory), neural networks, optimization, transformers, generative models, and AI workflows like RLHF, RAG and agents. Each one has the intuition, the math step by step, a tiny worked example and common pitfalls.

I run graphify over the notes to build the graph, which came out to 385 nodes and 736 edges. Then a Python script combines the graph, the notes and a list of walkthroughs into one page. Click a node to see its formula, double-click to read the whole note, or search across names and formula text. The nine walkthroughs, like “LLM generates the next token” or “Diffusion model draws an image”, step through a process with the arrow keys and light up the math each step uses.

Where it stands

Section 01, the math visualizer, is built. The folder is set up for more numbered sections, but none exist yet.
